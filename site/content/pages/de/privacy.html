Wer wir sind

Smart Casa ist eine unabhängige Website mit Produktempfehlungen für das Smart Home, gehostet auf GitHub Pages. Um uns zu kontaktieren, eröffne ein Issue auf der Issues-Seite des Repositorys oder schreibe uns über unsere im Seitenfuß verlinkten Social-Media-Profile.

Welche Daten wir erheben

Die Website erfordert kein Konto und wir erheben keine personenbezogenen Daten über Formulare. Derzeit setzen wir keine Analyse- oder Werbeskripte ein und speichern keine Cookies. Deine Einstellungen (Sprache, Textgröße und Augenschon-Modus) werden im lokalen Speicher deines Browsers auf deinem eigenen Gerät gespeichert und nie an uns übertragen.

Dritte

  • Schriften: Die Schriften der Website werden von unseren eigenen Seiten ausgeliefert, daher geht keine Anfrage an einen Schriftanbieter.
  • Hosting: GitHub Pages hostet die Website und kann Besuche gemäß der Datenschutzerklärung von GitHub protokollieren.
  • Produktbilder: Produktfotos werden meist von dieser Website selbst ausgeliefert (verkleinerte Kopien); fehlt eine Kopie, werden sie von den Bildservern von AliExpress geladen, sodass AliExpress dann deine IP-Adresse und Browserinformationen erhalten kann.
  • Shop-Links: Beim Klick auf einen Produktlink verlässt du unsere Website und gelangst zum Shop (AliExpress). Der Shop kann Cookies setzen, um uns einen Kauf zuzuordnen, und es gilt seine eigene Datenschutzerklärung.

Hinweis zu Affiliate-Links

Wir nehmen an Partnerprogrammen teil und erhalten möglicherweise eine Provision für qualifizierende Käufe über unsere Links, ohne zusätzliche Kosten für dich.

Kinder

Die Website richtet sich nicht an Kinder und wir erheben wissentlich keine Daten von ihnen.

Änderungen

Wir können diese Erklärung aktualisieren und zeigen das Datum der letzten Aktualisierung oben an. Wenn wir Analyse oder Werbung einführen, passen wir sie entsprechend an.
